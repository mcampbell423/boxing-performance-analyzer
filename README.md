# boxing-performance-analyzer

Code for a boxing performance analysis system using glove and bag sensors.

## Project layout

- `firmware/`: embedded code for glove IMUs and bag sensors
- `analysis/`: data collection, signal processing, and classifier training
- `dashboard/`: performance analysis application
- `data/sample_sessions/`: sample session data
- `tests/`: automated tests
- `hardware/`: wiring and bill of materials
- `docs/`: system design and test results
